# Pemberitahuan Pemrosesan Data Pihak Ketiga

> DRAF - wajib ditinjau oleh konsultan hukum Indonesia.

Dengan mengunggah atau mengelola data pemegang paten, inventor, dan kontak pihak ketiga, Anda menyatakan bahwa: (a) organisasi Anda memiliki dasar pemrosesan yang sah untuk data tersebut; (b) data hanya digunakan untuk pemantauan paten dan korespondensi yang relevan; (c) kontak prospek didokumentasikan sumber dan dasar pemrosesannya; dan (d) permintaan Subjek Data akan diteruskan dan ditangani tepat waktu.
